# ML Practice Notebooks

A collection of Google Colab notebooks exploring data preprocessing, exploratory data analysis, and machine learning using Python and Scikit-learn.

## Topics

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering and Scaling
- Classification Algorithms
- Clustering Techniques
- Dimensionality Reduction
- Model Evaluation

## Tech Stack

Python · Google Colab · NumPy · Pandas · Matplotlib · Seaborn · Scikit-learn

## Notebooks

Each notebook demonstrates practical implementations using datasets, covering data preparation, model training, and performance evaluation.

## Usage

1. Browse the notebooks in this repository.
2. Open a `.ipynb` file on GitHub.
3. Click **Open in Colab** if the badge is available, or download the notebook and upload it to [Google Colab](https://colab.research.google.com/).
4. Run the cells to explore the implementation.

## Purpose

Hands-on practice with data science and machine learning concepts through practical notebook-based implementations.
